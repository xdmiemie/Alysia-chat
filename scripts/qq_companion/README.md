# QQ companion scripts

The FeiyuVoice installer, local Applio configuration check, asset installer,
and FAISS worker live here. Run them from the project root as documented in
`docs/qq_companion/stage14a.md`.

The Q0-Q2 `start_all.ps1`, `stop_all.ps1`, and `doctor.ps1` scripts in the phase
plan have not yet been implemented. This folder does not start AstrBot or
SnowLuma by itself.
